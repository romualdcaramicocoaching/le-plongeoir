# Le Plongeoir - Starter Pack

Blog automatisé sur la natation (matériel, entraînement, enfants, plaisir de l’eau).

## Fonctionnalités
- Génération automatique d’articles via IA (mots-clés).
- Injection automatique de liens affiliés.
- Capture d’emails via Google Form + envoi de PDF.

## Installation rapide
1. Crée un repo GitHub et upload ce dossier.
2. Active GitHub Pages.
3. Configure les Secrets (LLM_ENDPOINT, LLM_API_KEY, POSTS_PER_RUN).
4. Ajoute tes mots-clés dans `content/keywords.csv`.
